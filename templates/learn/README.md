# {{name}}

Six small exercises. Each one is a file in `exercises/` with a `check` that fails until you fix the code.

## How it works

```bash
quill test
```

Quill runs every exercise and shows each check that fails, with both sides of it. Open the first exercise that fails, read the comment at the top, change the code, and run `quill test` again. When every file says `checks passed`, you're done.

| File | What you practise |
|---|---|
| `exercises/01-values.quill` | values and text |
| `exercises/02-numbers.quill` | exact numbers |
| `exercises/03-decisions.quill` | `when` |
| `exercises/04-data.quill` | `count of` and `average` |
| `exercises/05-text.quill` | `trim`, `lowercase`, `contains` |
| `exercises/06-money.quill` | money that never loses a cent |

To run one exercise and see what it says, use `quill run exercises/01-values.quill`.

`QUILL.md` in this folder is a short tour of the language.
