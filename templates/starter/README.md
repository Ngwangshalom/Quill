# {{name}}

A first Quill program: values, text, a list, a decision, a loop, a function, and a test.

## Run it

```bash
quill run hello.quill
```

## Test it

```bash
quill test
```

`check name == "Amina"` and the `--- example:` above `double` are tests. Change `name` to your own name and run `quill test` again: the check fails, and Quill shows you both sides.

## Try next

2. Write a function `triple`, with an example above it, and call it.
3. Run `quill explain hello.quill:10` to see how Quill reads line 10.
