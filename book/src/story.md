## Why Quill exists

Building a backend today means stitching together a framework, a database library, a validation library, a test runner and a pile of dependencies. Then production goes down anyway, because of a `null` nobody checked, a failure nobody handled, or a price that rounded wrong.

Quill was started to make that everyday work dramatically less painful: a language where code reads like what it means, mistakes are caught before anything runs, and every error explains itself.

## Timeline

| Date | Milestone |
|---|---|
| 13 October 2026 | Work on Quill begins. The first program, `say "Hello, World!"`, runs the same day. |
| 13 October 2026 | Quill is published on GitHub as an open-source project under the Apache 2.0 license. |
| 13 October 2026 | **v0.1.0**, the first release, with installers for macOS, Linux and Windows. |
| 13 October 2026 | **v0.2.0** adds arithmetic with exact decimals, values inside text, `var` and `set`, and `when`. |
| 13 October 2026 | The Quill book and the language specification are published, and every change to Quill is documented in them from now on. |
| 13 October 2026 | **v0.3.0** adds `quill update`, to choose and install any version from a menu, and a notice when a new version is out. |
