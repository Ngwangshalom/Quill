# What's Coming Next

Quill is young, and these features are designed but not built yet. The examples on this page show how they're planned to work. They don't run yet.

Functions, [money](money.md), [maybe](maybe.md), [failures](failures.md), [contracts](contracts.md) with ranges like `where 1..500`, and [asking for data](asking.md) with `get` and `sum` are in the language now. `for` is still there when each record needs its own step. A `when` can give a value, and `on` can give a value and carry on. A parameter's kind is `number`, `text`, `true/false`, a currency such as `USD`, a [type](types.md) such as `Booking`, `maybe` one of those, or `list of` one of those.

## And more

[Types](types.md) with rules on their fields are here, and so are [bringing in files](bring.md), [permits](permits.md), [JSON](json.md), [web requests](http.md), [AI models](ai.md) and [web services](web.md). Still ahead: a built-in module for databases (`bring db`), and contracts that Quill proves before the program runs. See the [README](https://github.com/Ngwangshalom/Quill#readme) for the full design.

Each of these will get its own chapter in this book as it's built. Want to help build one? Read the [contributor guide](https://github.com/Ngwangshalom/Quill/blob/main/CONTRIBUTING.md).
